# Bathroom Buddy
Bathroom Buddy is a web application inspired from a tablet-based application I discovered at my Dentists office's that allow clients make request for in demand toiletries. So I decided to make my own complete version. Which the businesses can use to manage, track, and fufill requests. 

## Features
- **Dashboard page:** Allows business to manage and track amount of requests and supplies.
- **Client Requests:** Clients allowed to make requests in real time.
- **Rate Limiting:** Prevents clients from abusing API's and spamming requests within a small time span.
- **Supplies Management:** Businesses can keep track of amount of supplies being used.

## Tech Stack
**Frontend:**
- React.js
- Tailwind CSS

**Backend**
- SpringBoot
- PostgresSQL
- Supabase
